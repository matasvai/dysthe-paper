# Preserved Dysthe reports

Archived on 5 November 2026. Paths below reproduce their original workspace layout. `manifest.json` records every copied file, SHA-256 checksum, source path and exclusion. Copies are byte-identical to their sources; original dates and model labels remain intact.

These documents include historical optical/canonical studies, spatial water-wave experiments and a separately versioned temporal potential-envelope investigation. The user also requested coverage of unrelated project chats; the cavitation worked solution is therefore retained under its original `output/pdf/cavitation-worked-solution` paths and is labelled as coursework in the chat catalogue. Historical studies do not become evidence for the active spatial water-wave baseline. Some original interpretations were corrected in later work; consult the accompanying dated research catalogue before citing a conclusion.

Editable LaTeX and its identified figure/table dependencies are retained. Earlier reports that used raster figures preserve those images as part of the original record. This archival operation checks file identity and literal dependencies; it does not recompile or scientifically revalidate every historical report. The manifest lists unresolved references and skipped macro placeholders.

Raw fields, neural checkpoints, ZIP duplicates, build logs, cached previews, third-party papers, resumes and unrelated filesystem material outside the reviewed chats are excluded. Files larger than 5 MB are recorded rather than silently truncated. The external stage-one report has a distinct directory and its original absolute source path is recorded.
