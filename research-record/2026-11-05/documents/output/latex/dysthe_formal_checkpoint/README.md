# Formal mathematical edition

Research checkpoint: September 10, 2026.

This package contains one complete LaTeX article and its 20 figure assets.
Numerical values are embedded in the source. No Python, BibTeX, simulation
reruns, or project-relative dependencies are required to typeset the report.

Compile from this folder with:

```bash
tectonic formal_report.tex
```

Alternatively, use XeLaTeX at least twice to resolve the contents, equations,
figures and bibliography. The article uses Latin Modern and standard LaTeX
packages. Network access may be required on the first run of a minimal TeX
installation to obtain missing packages or fonts.

This is a formal visual edition of the saved checkpoint, not a new experimental
batch. The report's reproduction commands refer to the complete research project;
the separate checkpoint archive contains scripts and saved numerical records.
The scientific plots remain color figures; the article typography is monochrome.
