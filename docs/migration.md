# Manuscript development

Use `codex/manuscript-outline` to refine the question and identify prior work.
The existing retrospective can inform scope; historical plasma results cannot
be represented as optical Dysthe evidence. Avoid copying unpublished third-party
PDFs into this public repository.

Add supported claims only after the experiment promotion gates pass. Every
claim needs a run manifest, figure/table, source revisions, limitations and an
accessible artifact location. Choose a journal after the contribution is clear.
The compiled initial outline contains no new results.
